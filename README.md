# 🎂 CakeStore E-Commerce

A simple and beautiful online cake store built with **Next.js** and **Sanity IO**.

## 🚀 Features
* Browse delicious cakes and view product details
* Interactive image gallery for each product
* Promotional home page banner
* Working shopping cart to add and adjust quantities

## 🛠️ Tech Stack
* **Frontend:** Next.js & React
* **Database / CMS:** Sanity.io
* **Hosting:** Vercel

## 💻 How to Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the website:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. Start the Sanity Studio (to manage cakes):
   ```bash
   cd studio
   npm run dev
   ```
   Open `http://localhost:3333` in your browser.
